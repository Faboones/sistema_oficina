# Sistema de Oficina Mecânica

Projeto desenvolvido em Python para praticar lógica de programação e criar um sistema de gerenciamento de clientes e veículos para uma oficina mecânica.

## Funcionalidades

- Cadastro de clientes.
- Listagem de clientes cadastrados.
- Busca de clientes pelo nome.
- Edição dos dados dos clientes.
- Exclusão de clientes.
- Cadastro e gerenciamento de veículos associados aos clientes.

## Tecnologias utilizadas

- Python 3
- Listas e dicionários
- Funções
- Estruturas condicionais e de repetição
- Tratamento de exceções

## Como executar

1. Instale o Python 3.
2. Clone este repositório ou baixe os arquivos.
3. Abra o terminal na pasta do projeto.
4. Execute:

   ```bash
   python main.py
   ```
